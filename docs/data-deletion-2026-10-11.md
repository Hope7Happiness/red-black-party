# 用户数据清理记录

对象：红黑牌线上游戏数据库。

2026-10-11 05:22:42 UTC，应站点所有者要求，通过临时鉴权接口，在 Cloudflare D1 的一个事务批次内执行：

```sql
DELETE FROM rooms;
SELECT COUNT(*) AS remaining FROM rooms;
```

线上返回（不包含玩家身份或房间内容）：

```json
{"deletedRooms":1,"remainingRooms":0,"checkedAt":"2026-10-11T05:22:42.119Z"}
```

随后通过 Sites 独立数据库读取接口复查 `DB.rooms`：`rows=[]`、`has_more=false`。数据库概览仅列出 `rooms` 一张业务表；项目未绑定 R2。昵称、玩家凭据、交牌、猜数和翻牌记录均存于该表的 `state` 字段，因此本次删除涵盖当前线上数据库中的全部游戏数据。开发环境的本地房间表也已清空。

网站仍部署并接受新游戏，新产生的数据不在本次历史清理范围内。临时清理接口及其运行时密钥将在清理后移除，不包含在公开源码快照中。

浏览器下次加载新版本时会清理旧的 `rbp:*` 本地存储（昵称、房间及身份凭据）。未重新加载的页面内存，以及离线或不再访问的设备，无法远程确认已清除。

## 证明范围

以上证明的是清理时刻在线业务表为空，不是所有介质上不存在副本的证明。Cloudflare D1 的 [Time Travel](https://developers.cloudflare.com/d1/reference/time-travel/) 默认始终开启，免费/付费计划分别保留最近 7/30 天的恢复历史；本次 SQL 删除不能立即移除这些历史副本。平台访问日志、托管方备份和用户设备缓存不在当前工具的可删除或可验证范围内。因此不能声称“所有地方零留存”。
